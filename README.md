## 🚀 How to Run Locally

### Option 1: Direct File Open
Double click on `index.html` or right-click and choose **Open with > Google Chrome** (or Edge/Brave/Firefox).

### Option 2: Local HTTP Server (Python)
Open a terminal in the folder and run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Push this folder to your GitHub repository `https://github.com/Dharmeshkumar2327/portfolio` (or create a repo named `Dharmeshkumar2327.github.io`).
2. Go to **Settings** > **Pages** in the GitHub repository.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
4. Your portfolio will be live at:
   `https://dharmeshkumar2327.github.io/portfolio` (or `https://dharmeshkumar2327.github.io/`)

### 2. Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project directory, follow the 3 prompts, and your site is live instantly with an SSL certificate.

### 3. Netlify
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop the `dharmesh-kumar-portfolio` folder directly into the browser.
3. Your site is live immediately!
